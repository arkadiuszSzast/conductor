## 8. Dependency and acceptance map

Safe parallel graph: A → (B || C || D || F test authoring); E config preparation after A, integration after B/C/D; F end-to-end after E; documentation/review/quality last. B exclusively owns Store/engine/migrations; D API; E daemon/main/exports/manifests/lockfile. Cross-owner interface edits return to A/E rather than conflicting patches.

Actual OpenCode project dogfood is deliberately a separately run follow-up, not a checkbox that can be marked passed using mocks.
